# Feature families

One folder per family. Each page follows the donor pattern: behavior, how donors do it, what the notes found, where it touches Domicile, lineage, sources.

- [input](input/README.md): device configuration, finger axes and momentum boundaries.
- [gestures](gestures/README.md): native phases, ownership, shell bindings and touchscreen contacts.
- [pointer](pointer/README.md): image visibility, named shapes, motion and constraints.
- [keyboard-and-text](keyboard-and-text/README.md): typed chords, shortcut inhibition and text composition.
- [seats](seats/README.md): brokered device access and independent logical input participants.
- [capture](capture/README.md): portal streams, direct frame capture and foreign-window enumeration.
- [clipboard-dnd](clipboard-dnd/README.md): selections, clipboard history and drag-and-drop lifetimes.
- [outputs](outputs/README.md): display profiles, fullscreen requests, fractional scale and gamma ramps.
- [session](session/README.md): idle, lock, portal permissions, activation and component recovery.
- [terminal](terminal/README.md): native terminal protocols, software echo timing and remote transport.
- [layout](layout/README.md): placement trees, scrolling layouts and window lifetime.
- [workspaces](workspaces/README.md): workspace identity, homes, overview and switching.
- [windows](windows/README.md): criteria, marks, content density, focus and native state.
- [bindings-and-modes](bindings-and-modes/README.md): chord ownership and binding modes.
- [ipc-scripting](ipc-scripting/README.md): desktop state, events and shell scriptability.
- [bar-and-notify](bar-and-notify/README.md): bar modules, notifications and system panels.
- [feel-and-animation](feel-and-animation/README.md): scroll sequences and animation continuity.
- [effects](effects/README.md): background blur, clipping, shadows and window animations.
- [browser-windows](browser-windows/README.md): web apps, window groups, and browser prompts drawn in the shell.
- [shell-surfaces](shell-surfaces/README.md): panels, overlays and popup boundaries in one desktop page.
- [aura-wm](aura-wm/README.md): Aura and Ash window states, desks, overview, cycling and display topology.
- [engine-mechanisms](engine-mechanisms/README.md): GPU backends, patch discipline and typed page and host calls.
- [build-and-packaging](build-and-packaging/README.md): Nix engine artifacts and build identity.
- [protocols](protocols/README.md): rows and findings beside the [protocol map](../03-wayland-protocols/README.md).
