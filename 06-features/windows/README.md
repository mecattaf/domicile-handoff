# Windows

- [Window marks, selections and trails](marks-and-advanced-marking.md): Marks attach stable names to windows; selections and trails add multi-window operations and ordered return paths.
- [Window criteria and opening rules](criteria-and-window-rules.md): Criteria select windows by attributes, and rules apply actions when matching windows appear or change relevant properties.
- [Per-window content scale](content-scaling.md): Content scaling changes a window’s content density independently of monitor scale and overview transforms.
- [Pointer focus and activation policy](focus-and-urgency.md): Focus policy decides which window receives keys after pointer movement, directional navigation, closing and activation requests.
- [Native window state requests](native-state-requests.md): A native client requests maximize or fullscreen state; the shell decides placement and reports the states represented by that placement.
