# Workspaces

- [Workspaces and screen homes](workspace-model-and-homes.md): Workspaces group windows, while a screen home records where a workspace is shown or returns when selected.
- [Workspace and window overview](overview.md): Overview shows live windows in workspace tiles and supports selecting, moving and steering among those tiles.
- [Workspace switching and slides](workspace-switching-and-slides.md): Workspace switching changes the shown workspace while a screen-local slide keeps the transition continuous.
