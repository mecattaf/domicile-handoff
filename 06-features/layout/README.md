# Layout

- [Scrolling rows and columns](scrolling-layout.md): A scrolling layout keeps useful window sizes while a viewport moves through columns and the windows within them.
- [Nested splits and container layouts](tiling-splits-and-containers.md): A layout tree groups windows into splits, tabs and stacks, with focus and movement defined at each level.
- [Floating groups and the scratchpad](floating-and-scratchpad.md): A floating group moves independently of the tiled tree; the scratchpad hides a window and recalls it without consuming a workspace slot.
- [Window placement across shell reloads](layout-retention-across-reload.md): A shell reload preserves client windows while replacing the page that holds the shell’s layout state.
